# 메르칸티스 — 실시간 멀티플레이 서버

Express + Socket.io로 만든 실시간 서버입니다. 회원가입/로그인 없이, 상단 이름(태그)과 4자리 방 코드만으로 여러 명이 접속해 플레이할 수 있습니다.

## 구성

- `server.js` — Express + Socket.io 서버 본체 (방/로비/체인게임 라운드/영토 경매 진행 관리)
- `game-logic.js` — 체인게임 규칙(덱, 침공/방벽/근위대/밀약, 파산 판정)과 영토 경제 규칙(등수 코인, 영토 소득, 경매, 목표 코인 판정)
- `public/index.html` — 브라우저에서 접속하는 클라이언트 화면
- `integration-test.js` — 4인 자동 플레이 통합 테스트: 방 생성→참가→게임 시작→(체인게임 라운드+영토 경매) 반복→목표 코인 20 달성까지 자동 진행 (검증용, 배포에는 불필요)

## 로컬에서 실행하기

```bash
npm install
npm start
```

서버가 뜨면 브라우저에서 `http://localhost:3000` 접속. **같은 컴퓨터 안에서는** 탭을 여러 개 열어 바로 테스트할 수 있습니다.

## 다른 컴퓨터에 있는 사람과 같이 하려면

로컬에서만 실행하면 `localhost`는 본인 컴퓨터에서만 열려요. 다른 사람이 접속하려면 아래 중 하나가 필요합니다.

### 방법 A — 빠르게 임시로 열어보기 (ngrok 등 터널링)
```bash
# 별도로 ngrok 설치 후
ngrok http 3000
```
발급되는 `https://xxxx.ngrok-free.app` 같은 주소를 친구들에게 공유하면 바로 접속 가능합니다. 테스트용으로 가장 빠른 방법이지만, 터미널을 끄면 링크도 끊깁니다.

### 방법 B — 무료 호스팅에 올려서 상시 운영
Render, Railway, Fly.io 같은 곳에 올리면 항상 켜져 있는 주소를 받을 수 있습니다. 공통 순서는 비슷합니다.
1. 이 폴더를 GitHub 저장소로 올리기
2. 해당 서비스에서 "새 웹 서비스" 생성 → 그 GitHub 저장소 연결
3. 빌드 명령 `npm install`, 시작 명령 `npm start` 지정
4. 배포 후 발급되는 `https://your-app.onrender.com` 같은 주소를 친구들에게 공유

서비스마다 세부 화면은 다르니, 선택한 곳의 최신 가이드를 확인하는 걸 추천해요.

### 방법 C — 직접 서버(VPS)에 올리기
클라우드 서버 하나를 빌려서 Node.js 설치 후 `npm install && npm start`로 띄우고, 80/443 포트를 열어주면 됩니다. pm2 같은 프로세스 매니저로 백그라운드 실행 및 재시작을 관리하는 걸 추천해요.

## 알아두면 좋은 점

- **방 상태는 메모리에만 저장**됩니다. 서버를 재시작하면 진행 중이던 모든 방이 사라집니다 (별도 DB 연동 없음).
- 호스트가 아니어도 누구나 방을 만들 수 있고, 방을 만든 사람이 자동으로 "게임 시작" 버튼을 가진 호스트가 됩니다.
- 게임은 별도의 전초전/본게임 구분 없이 **체인게임 한 라운드 → 등수별 코인 지급 → 영토 소득 지급 → 목표 코인(20) 도달 확인 → 영토 경매 1회 → 다시 체인게임...** 단일 루프로 진행되며, 누군가 목표 코인에 먼저 도달하면 즉시 종료됩니다.
- 한 턴/한 경매에 각각 25초 / 20초 동안 반응이 없으면 서버가 자동으로 기본 행동(가장 약한 침공 카드, 없으면 방벽/근위대 · 입찰은 0)으로 대신 처리합니다.
- 목표 코인, 등수별 코인, 영토 수익 범위, 시작 코인 등은 `game-logic.js` 상단 상수(`GOAL_COINS`, `COIN_TABLE`, `START_COINS`, `LAND_YIELD_MIN`/`LAND_YIELD_MAX`)에서 조정할 수 있습니다.

## 검증 내역

`integration-test.js`로 실제 Socket.io 클라이언트 4개를 띄워 방 생성→참가→게임 시작→(체인게임 라운드 진행 + 영토 경매) 반복→목표 코인 20 달성으로 종료까지 자동 플레이시켜, 모든 클라이언트가 서버와 동일한 최종 상태(승자·코인)로 동기화되는 것을 확인했습니다. 로직을 수정한 뒤에는 아래처럼 재검증할 수 있습니다.

```bash
npm install
npm install socket.io-client --save-dev   # 테스트 전용
node server.js &
node integration-test.js
```
